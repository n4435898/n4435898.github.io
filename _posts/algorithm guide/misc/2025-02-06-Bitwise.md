# XOR$\oplus$

Properties:

1. Commutativity: $A\oplus B = B\oplus A$
2. Associativity: $(A\oplus B)\oplus C = A\oplus(B\oplus C)$
3. Identity: $A\oplus{0} = A$
4. Involution: $A\oplus A = 0$
5. Cancellation: $(A\oplus B) \oplus B = A$
6. Bitflip: $A\oplus{111...111} = \neg A$

Notable tips:

- Applying XOR of the same number odd times is the same at doing it once. If you apply it an even number of times, it cancels out and becomes identical.
